# Phase 6. Verification, PWA, and hosting

The service worker caches the public campus asset, icons, and an offline fallback. It fetches authenticated pages and parking data over the network. An offline page directs the user to reconnect.

## Local verification

Run the following from the materialized project after applying the database setup.

```powershell
npm test
npm run typecheck
npm run build
npm run dev
```

Open `http://localhost:3000`. Stop the development server and run `npm run start` to test the built app and service worker. For the database test, use a dedicated test database with the migrations applied. Set `APP_ENV=demo`, `CONFIRM_DATABASE_TEST=yes`, and the test owner’s `MIGRATION_DATABASE_URL`. Then run `npm run test:database`. The test removes its own fixtures when it finishes.

| Check | Evidence to collect |
| --- | --- |
| Auth and roles | Test Campus and Visitor signup, email confirmation, reset, pending approval, each of the six roles, and suspension. In a pilot, verify TOTP for Security Officers and Administrators. |
| Domain | Rejection of invalid or duplicate vehicles, excluded visitors, concurrent claims, repeated claim and release requests, and closure during an active session. |
| Live state | A second device updates after park and leave. Offline state blocks writes, and reconnect refreshes before a claim. |
| Map and mobile | Compare the 2D plan to the supplied HTML. Check road and building search, selection and live status, keyboard access, pinch and pan, and the parking action below the map. Review portrait and landscape on Android Chrome and iPhone Safari. Confirm the directions link reaches the Katubedda campus address. |
| Operations | Verify that drivers receive `403` on officer and admin endpoints, officers can correct a session with a reason and receive `403` on admin endpoints, and admins can assign roles with an audit record. Check closure, reopening, targeted notices, and CSV. |
| PWA | Install where supported, open from the home screen, disconnect, and check fallback. |

## Deploy the student demo

1. **Commit the app to Git.** Include the source and the `package-lock.json` generated by `npm install`. Check `git status` for leaked local environment files and dumps before pushing to the Git host you will connect.
2. **Prepare Supabase.** Apply migrations and seed the demo project. Enable the limited runtime login and bootstrap a confirmed admin account. Configure SMTP for signups with external addresses. [Supabase SMTP setup](https://supabase.com/docs/guides/auth/auth-smtp)
3. **Import into Vercel.** The repository root contains `package.json`. Keep **Root Directory** at the repository root, use the Next.js preset, and use Node.js 24. The install command is `npm ci` and the build command is `npm run build`. The build generates the public campus and icon assets. The Vercel CLI can also deploy from this directory after linking the project. [Next.js on Vercel](https://vercel.com/docs/frameworks/full-stack/nextjs) · [Vercel Node.js versions](https://vercel.com/docs/functions/runtimes/node-js/node-js-versions) · [Vercel CLI deployment](https://vercel.com/docs/cli/deploy)
4. **Set Vercel variables.** Add `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`, `DATABASE_URL` (limited role, transaction pooler), `DATABASE_SSL_CA` (the Supabase CA PEM contents), `APP_ORIGIN` (canonical HTTPS URL), and `APP_ENV=demo`. Set `STALE_SESSION_HOURS` only to override the default. Keep owner credentials local. If testing Auth on a preview, use a separate Auth environment with a stable preview origin and matching redirect configuration. [Vercel environment variables](https://vercel.com/docs/environment-variables)
5. **Configure the public URL.** Set the Supabase Site URL to the canonical HTTPS origin and allow its exact `/auth/confirm` callback. Apply the confirmation and recovery email templates from Phase 1. Redeploy after changing public environment variables. Set up DNS in Vercel if using a custom domain. [Supabase redirect URLs](https://supabase.com/docs/guides/auth/redirect-urls)
6. **Smoke-test HTTPS.** Sign up with two inboxes you control, confirm and complete a parking session, confirm cross-device updates, and test an officer action and a targeted announcement.

Vercel Hobby is for eligible personal, non-commercial use. Free Supabase projects may pause after inactivity. Use university-approved plans and dedicated services for a campus pilot. [Vercel Hobby](https://vercel.com/docs/plans/hobby) · [Supabase project pausing](https://supabase.com/docs/guides/platform/free-project-pausing)

## Continuous integration and deployment

Push a branch and open a pull request to run the app and database checks. A push or merge to `main` starts GitHub Actions and Vercel's production build in parallel. The Vercel Git connection publishes successful builds from `main` to the [production site](https://uom-smart-parking.vercel.app/). [Vercel for GitHub](https://vercel.com/docs/git/vercel-for-github)

| Check | What it verifies |
| --- | --- |
| App checks | Installs from `package-lock.json` on Node.js 24, generates assets, and runs campus tests, TypeScript, and the Next.js production build. |
| PostgreSQL checks | Creates a disposable PostgreSQL service, installs the Auth and Realtime fixtures, runs the migrations, and tests eligibility, concurrent claims, retries, limits, and releases. |
| Production smoke test | After both CI jobs pass on `main`, waits for Vercel's success status on the same commit. Checks the homepage, sign-in redirect, access denial for the protected API, and the PWA manifest over HTTPS. |

Review each release in [GitHub Actions](https://github.com/nadija-smwg/uom-smart-parking/actions/workflows/check.yml) and [Vercel Deployments](https://vercel.com/nadija/uom-smart-parking/deployments). Keep production database credentials in Vercel. The database tests use the service container, and the smoke job only needs GitHub's read-only workflow token. [GitHub PostgreSQL service containers](https://docs.github.com/en/actions/tutorials/use-containerized-services/create-postgresql-service-containers)

## Operate and recover

- Apply backwards-compatible migrations before new app features depend on them. Roll back application code to a schema-compatible deployment if a release fails.
- Monitor Vercel errors, database connections, mail delivery, and live status. Configure Auth abuse limits and platform rate limits before opening public registration.
- Set a backup schedule and retention, rehearse restore to a separate project, and keep an owner contact. Protect database exports and rotate exposed secrets. [Supabase backups](https://supabase.com/docs/guides/platform/backups)
- For a campus pilot, reconcile the A3 PDF and surveyed inventory, approve access and retention rules, and onboard staff separately. Use `APP_ENV=pilot` only in that environment. Create and verify zones and spaces through Operations. Verify the physical space codes and roles before allowing real claims.

**Exit check** Verify the real Vercel URL, email callbacks, two-device parking, role boundaries, and mobile PWA flow. The hosted test is complete once those checks pass on the chosen environment.

```js
const CACHE = "uom-parking-public-v3";
const SAFE = ["/campus.json", "/icon-192.png", "/icon-512.png", "/offline.html"];
self.addEventListener("install", (event) => {
  event.waitUntil(caches.open(CACHE).then((cache) => cache.addAll(SAFE)));
});
self.addEventListener("activate", (event) => {
  event.waitUntil(caches.keys().then((keys) => Promise.all(keys.filter((key) =>
    key.startsWith("uom-parking-public-") && key !== CACHE).map((key) => caches.delete(key))))
    .then(() => self.clients.claim()));
});
self.addEventListener("fetch", (event) => {
  const url = new URL(event.request.url);
  if (event.request.method !== "GET" || url.origin !== self.location.origin) return;
  if (event.request.mode === "navigate" && url.pathname !== "/api" && !url.pathname.startsWith("/api/")) {
    event.respondWith(fetch(event.request, { cache: "no-store" })
      .catch(async () => (await caches.open(CACHE)).match("/offline.html")));
  } else if (SAFE.includes(url.pathname) && !url.search) {
    event.respondWith((async () => {
      const cache = await caches.open(CACHE);
      let result;
      try { result = await fetch(event.request); }
      catch (error) {
        const cached = await cache.match(event.request);
        if (!cached) throw error;
        return cached;
      }
      if (result.ok) await cache.put(event.request, result.clone()).catch(() => {});
      return result;
    })());
  }
});
```

### `scripts/icons.mjs`

<!-- file: scripts/icons.mjs -->

```js
import { mkdir, writeFile } from "node:fs/promises";
import { deflateSync } from "node:zlib";

const glyph = [
  "11110","10001","10001","11110","10000","10000","10000",
];
const crc32 = (bytes) => {
  let crc = 0xffffffff;
  for (const value of bytes) {
    crc ^= value;
    for (let i=0;i<8;i++) crc=(crc>>>1) ^ ((crc&1) ? 0xedb88320 : 0);
  }
  return (crc ^ 0xffffffff) >>> 0;
};
function chunk(type,data) {
  const header=Buffer.alloc(8);
  header.writeUInt32BE(data.length);
  header.write(type,4);
  const tail=Buffer.alloc(4);
  tail.writeUInt32BE(crc32(Buffer.concat([header.subarray(4),data])));
  return Buffer.concat([header,data,tail]);
}
function icon(size) {
  const pixels = Buffer.alloc((size*3+1)*size);
  const scale = Math.floor(size/14);
  const x0 = Math.floor((size-5*scale)/2);
  const y0 = Math.floor((size-7*scale)/2);
  for (let y=0;y<size;y++) for(let x=0;x<size;x++) {
    const row = Math.floor((y-y0)/scale);
    const col = Math.floor((x-x0)/scale);
    const filled = glyph[row]?.[col] === "1";
    const offset = y*(size*3+1)+1+x*3;
    const color = filled ? [32,41,37] : [237,107,55];
    pixels.set(color,offset);
  }
  const info = Buffer.alloc(13);
  info.writeUInt32BE(size); info.writeUInt32BE(size,4); info[8]=8; info[9]=2;
  return Buffer.concat([Buffer.from([137,80,78,71,13,10,26,10]),
    chunk("IHDR",info),chunk("IDAT",deflateSync(pixels)),chunk("IEND",Buffer.alloc(0))]);
}
await mkdir("public",{recursive:true});
for(const size of [192,512]) await writeFile("public/icon-"+size+".png",icon(size));
```

```js
  function rows(name) {
    const match = html.match(new RegExp("const " + name + "=(\\[[^;]+\\]);"));
    assert.ok(match, name);
    return JSON.parse(match[1].replaceAll("'", '"'));
```

```js
import assert from "node:assert/strict";
import { randomUUID, randomInt } from "node:crypto";
import postgres from "postgres";

const { APP_ENV, MIGRATION_DATABASE_URL: url, CONFIRM_DATABASE_TEST } = process.env;
if (APP_ENV !== "demo" || CONFIRM_DATABASE_TEST !== "yes" || !url)
  throw new Error("Use an isolated TEST project with APP_ENV=demo and CONFIRM_DATABASE_TEST=yes.");
const db=postgres(url,{max:5,prepare:false});
const [first,second,zone,vehicleA,vehicleB,spaceA,spaceB,keyA,keyB] = Array.from({length:9},randomUUID);
const code="Z"+randomInt(10000,99999);
const timeout = () => ({ x:40, y:40, w:20, h:20, r:0, type:"box" });
const claim=(person,vehicle,space,key)=>db`select app.claim(${person},${vehicle},${space},${key},false) as id`;
try {
  await db.begin(async (tx)=>{
    await tx`insert into auth.users(id,email) values (${first},${first+"@example.test"}),(${second},${second+"@example.test"})`;
    await tx`insert into app.profiles(id,name,registration,role,verified)
      values (${first},'Test driver A','campus','student',true),(${second},'Test driver B','visitor','visitor',true)`;
    await tx`insert into app.vehicles(id,user_id,kind) values (${vehicleA},${first},'bicycle'),(${vehicleB},${second},'bicycle')`;
    await tx`insert into app.zones(id,code,name,category,proposed_capacity,geometry)
      values (${zone},${code},'Transaction test fixture','bicycles',2,${tx.json(timeout())})`;
    await tx`insert into app.spaces(id,zone_id,code,x,y) values
      (${spaceA},${zone},${code+"-001"},35,35),(${spaceB},${zone},${code+"-002"},45,45)`;
    await tx`insert into app.access_rules values(${zone},'student','bicycle')`;
  });
  await assert.rejects(claim(second,vehicleB,spaceA,keyB),/PARKING_FORBIDDEN/);
  await db`insert into app.access_rules values(${zone},'visitor','bicycle')`;
  const attempts=await Promise.allSettled([claim(first,vehicleA,spaceA,keyA),claim(second,vehicleB,spaceA,keyB)]);
  const a=attempts[0].status==="fulfilled";
  const success=a?attempts[0]:attempts[1];
  const loser=a?attempts[1]:attempts[0];
  assert.equal(success.status,"fulfilled");
  assert.equal(loser.status,"rejected");
  assert.match(String(loser.reason),/SPACE_UNAVAILABLE/);
  const actor=a?first:second, vehicle=a?vehicleA:vehicleB, key=a?keyA:keyB;
  const [{id}]=success.value;
  assert.equal((await claim(actor,vehicle,spaceA,key))[0].id,id);
  await assert.rejects(claim(actor,vehicle,spaceB,key),/REQUEST_REUSED/);
  await assert.rejects(claim(actor,vehicle,spaceB,randomUUID()),/ACTIVE_SESSION_LIMIT/);
  await db`update app.zones set open=false where id=${zone}`;
  const endKey=randomUUID();
  const [released]=await db`select app.release(${actor},${id},${endKey},null) as id`;
  assert.equal(released.id,id);
  const [{count}]=await db`select count(*)::int as count from app.activity where target=${id} and action='session.end'`;
  assert.equal(count,1);
  assert.equal((await db`select app.release(${actor},${id},${endKey},null) as id`)[0].id,id);
  await assert.rejects(claim(first,vehicleA,spaceA,randomUUID()),/SPACE_UNAVAILABLE/);
  console.log("PostgreSQL checks passed: eligibility, concurrent claim, request replay, limits, closure and release.");
} finally {
  try {
    await db.begin(async(tx)=>{
      await tx`delete from app.activity where actor in (${first},${second})`;
      await tx`delete from app.requests where actor in (${first},${second})`;
      await tx`delete from app.sessions where space_id in (${spaceA},${spaceB})`;
      await tx`delete from app.access_rules where zone_id=${zone}`;
      await tx`delete from app.spaces where id in (${spaceA},${spaceB})`;
      await tx`delete from app.zones where id=${zone}`;
      await tx`delete from app.vehicles where id in (${vehicleA},${vehicleB})`;
      await tx`delete from app.profiles where id in (${first},${second})`;
      await tx`delete from auth.users where id in (${first},${second})`;
    });
  } finally { await db.end(); }
}
```

```yaml
          const statusUrl = new URL(`/repos/${GITHUB_REPOSITORY}/commits/${GITHUB_SHA}/statuses`, GITHUB_API_URL);
          const deadline = Date.now() + 7 * 60_000;
          let deployment;

          while (Date.now() < deadline) {
            const response = await fetch(statusUrl, {
              headers: { Authorization: `Bearer ${GH_TOKEN}` },
              signal: AbortSignal.timeout(15_000),
            });
            assert.ok(response.ok, `GitHub commit statuses returned HTTP ${response.status}`);
            deployment = (await response.json()).find((status) =>
              status.context === "Vercel" && status.target_url?.startsWith(project));
            if (deployment?.state === "success") break;
            if (deployment?.state === "failure" || deployment?.state === "error") {
              throw new Error(`Vercel reported ${deployment.state}: ${deployment.target_url}`);
            }
            await delay(15_000);
          }
          assert.equal(deployment?.state, "success", "Vercel did not report a successful deployment for this commit");
          console.log(`Vercel deployed ${GITHUB_SHA}: ${deployment.target_url}`);

          const get = (path) => fetch(origin + path, { redirect: "manual", signal: AbortSignal.timeout(15_000) });
          const home = await get("/");
          assert.equal(home.status, 200);
          assert.match(await home.text(), /id="atlas-title"/);
          const plate = await get("/campus-atlas.webp");
          assert.equal(plate.status, 200);
          assert.match(plate.headers.get("content-type") ?? "", /image\/webp/);
          assert.equal(Buffer.from(await plate.arrayBuffer()).toString("ascii", 8, 12), "WEBP");
          const parking = await get("/parking");
          assert.equal(parking.status, 307);
          assert.equal(new URL(parking.headers.get("location"), origin).pathname, "/account");
          const api = await get("/api/v1/home");
          assert.equal(api.status, 401);
          assert.match(api.headers.get("cache-control"), /no-store/);
          const manifest = await get("/manifest.webmanifest");
          assert.equal(manifest.status, 200);
          assert.equal((await manifest.json()).display, "standalone");
          console.log(`Production smoke test passed: ${origin}`);
```
